## Why this job looks different from the others

`skills/tmc-case-study/SKILL.md` requires school/client permission, the actual trip and objective, the actual challenge, TMC's actual intervention, the actual outcome, a testimonial source if used, media permission if visual, and a source for any quantitative claim — all known or explicitly marked missing — **before** a case study is created. None of that exists in this workspace right now: there is no verified school outcome on file.

The rule that matters most here: "Never invent a before/after." So instead of a fabricated example, this job delivers the exact shape a real case study will take, with every factual slot marked, so a real one can be produced quickly once a school gives permission and the facts are supplied.

## Required inputs before this can become a real, publishable case study

- School/client name, and their explicit permission to be named (or a decision to anonymise)
- The trip/programme in question
- The stated objective for that trip
- The actual challenge or complication the school faced
- What TMC specifically did about it
- The actual outcome — in the client's own account, not an assumed result
- A testimonial, if one exists, quoted exactly and attributed with permission
- Media permission if any photo/video is to be used
- A source for any number used (attendance, satisfaction score, repeat-booking rate, anything quantitative)
