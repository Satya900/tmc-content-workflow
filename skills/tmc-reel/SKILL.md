# TMC Reel

## Core short-form structure
The Marketing Template's informational video logic is:
Opening -> value -> CTA.
For Reels, remove long self-introductions and long credibility seeding.

## Default structure
1. 1-second hook
2. Problem
3. 2–4 value points
4. TMC reframe / perspective
5. One CTA

## Timing guide
- Hook: 0–2 sec
- Problem: 2–7 sec
- Value: 7–30 sec
- Reframe: 30–40 sec
- CTA: final 3–5 sec

Adjust naturally for 20–60 second formats.

## Case-study Reel
Use:
Hook -> Situation -> Complication -> Question -> Answer -> Verified Outcome -> CTA

## Visual sourcing
Prefer approved TMC tour montage footage, B-roll, trip moments, logistics, teachers, landmarks and student activities where permissions allow.

## Rules
- Strong first line.
- No "Hi, my name is..." opening for Reels.
- Do not make factual claims just to improve the hook.
- Keep on-screen text concise.
- Never fabricate a student story.
- Add subtitle-ready phrasing.
- The reel should still make sense with audio muted when on-screen text is requested.

## Output
- concept
- spoken script
- on-screen text
- shot/B-roll direction
- caption
- CTA
- claim flags
