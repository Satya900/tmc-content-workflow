# TMC Editorial QA

## Review order
1. Strategy fit
2. Audience fit
3. Factual support
4. TMC differentiation
5. Structure
6. Voice
7. CTA
8. Media/permission risk
9. Formatting/platform fit

## Checks
### Strategy
- TOUR or MARKETING correctly classified?
- Clear objective?
- Correct pillar?
- Correct funnel stage?

### Audience
- One primary reader?
- Is the problem meaningful to that reader?

### Differentiation
Ask:
"Could a generic school-tour operator publish this unchanged?"
If yes, rewrite.

### Voice
Reject:
- generic inspiration
- brochure copy
- hard-selling language
- empty superlatives
- jargon-heavy academic phrasing
- fake founder voice

Prefer:
- warm authority
- specific examples
- practical usefulness
- honest complexity

### Claims
Flag:
- numbers
- years
- safety records
- prices
- visa/travel rules
- educational outcomes
- testimonials
- named schools
- incidents
- curriculum claims

### CTA
- one clear action maximum
- CTA not required on every piece

## Output
Return:
- PASS / REVISE / BLOCK
- issues by severity
- exact lines or sections to change
- corrected version when appropriate
- claims requiring verification
- permission/media concerns
