# TMC Claude Skills Pack

Purpose: make Claude follow The Modern Classroom (TMC) strategy consistently across content planning, marketing carousels, tour photo dumps, LinkedIn, blogs, newsletters, reels, case studies, image selection, QA, and monthly recommendations.

## Recommended installation
Copy the skill folders into the skills directory used by your Claude environment. Each skill is self-contained around a specific use case and has a `SKILL.md`.

## Important operating model
- TMC strategy is the source of truth.
- The Marketing Template provides the content-generation mechanics.
- External SEO/blog skills may assist research, SEO, schema, and editorial checks.
- Human review is mandatory before publishing.
- Never invent TMC claims, student outcomes, safety records, prices, testimonials, school permissions, or trip facts.

## Skill order
1. `tmc-core-context`
2. `tmc-content-strategist`
3. Format skill: carousel / LinkedIn / blog / newsletter / reel / case study / tour photo dump
4. `tmc-photo-selector` where images are needed
5. `tmc-editorial-qa`
6. `tmc-monthly-strategist` for performance-led planning

## Content categories
### Tour content
Real TMC trip documentation. Experience-led. Photos determine the story.

### Marketing content
Strategic positioning and lead generation. Strategy determines the story; approved tour photos support it.
