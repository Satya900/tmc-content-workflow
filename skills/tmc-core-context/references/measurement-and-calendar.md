## Marketing calendar format
One row per placement. The first eight columns are the workbook's calendar. The rest link it to TMC's job records and tracker.

| Column | Values |
|---|---|
| Posting date | YYYY-MM-DD |
| Platform | LinkedIn (Yasin), LinkedIn (company), Instagram, Facebook, Email, Blog, Website, WhatsApp, YouTube, X |
| Content bucket | 1 to 7 (`content-buckets.md`) |
| Needs and emotions | Fear, Pain point, Problem, Need, Desire, Fantasy + the specific item |
| Content strategy (delivery type) | Infographic, carousel, text post, blog, video script, email, case study, lead magnet |
| Content topic | Working title |
| Status | INTAKE, DRAFT, NEEDS_INPUT, REVIEW, CHANGES_REQUESTED, APPROVED, RENDERING_PENDING, EXPORTED, PUBLISHED |
| Caption | Draft caption or first line |
| Content ID | `TMC-YYYYMMDD-<FORMAT>-NNN` |
| Audience | From `audience-personas.md` |
| Angle | One of the 33 angles |
| Funnel stage | awareness, consideration, proof, conversion, nurture |
| Category | TOUR or MARKETING |
| Proof needed | Claim IDs or "none" |
| Version and file link | Latest version and its file |
| Live URL | After publication only |

Example row: `2026-11-12 | LinkedIn (company) | 7 | Problem: comparing two proposals | Text post | Five questions to ask before signing a tour proposal | DRAFT | "Two proposals, same destination, very different trips." | TMC-20261112-LI-001 | Principal | Questions to ask before | consideration | MARKETING | none | v001 jobs/... | -`

## Metrics by platform
Collect these monthly. Missing data is unknown, not zero. State the reporting window.

| Platform | Metrics |
|---|---|
| Instagram | Total posts, new posts in period, followers, new followers, profile visit to follow conversion, engagement rate (Ninjalytics is the stated tool), saves and shares, followers gained from live sessions |
| Facebook | Posts in period, followers, new followers, post reach, engagement rate, video views |
| LinkedIn | Posts, total connections or followers, new connections, reach, search appearances |
| YouTube | Videos posted, average view duration, total views, total subscribers, new subscribers |
| Email | Database size, emails sent, open rate, click-through rate, bounce rate |
| Website | Session duration, new users, returning users, exit rate on home, programmes and enquiry pages |
| Lead magnets | New contacts generated |
| Blog | Number of blogs, total views, time spent |

## Business KPIs
These decide success. Reach metrics only explain them.

1. **Leads generated:** enquiries and bookings received.
2. **Qualified school conversations:** conversations with decision-makers at target-segment schools.
3. **Conversion rate:** share of leads that become customers.
4. **Website traffic and behaviour.**
5. **Social engagement:** likes, comments, shares, follower growth.
6. **Customer feedback:** collected and analysed from schools, parents and students.

Where possible, tag each lead with the content ID that started it.

## Monthly review decisions
For each bucket, platform and format, recommend Continue, Improve, Test, Reduce or Stop, with the evidence. Keep the reasoning for next month's calendar.
